# WORKER Practice Project

## Общая информация
Данный репозиторий содержит программную реализацию кейс-задачи № 3, выполненной в рамках прохождения технологической (проектно-технологической) практики.

## Цель работы
Целью работы является разработка программного модуля, реализующего класс WORKER, предназначенный для хранения и обработки информации о работниках организации с использованием объектно-ориентированного подхода.

## Описание функциональности
Разработанная программа обеспечивает:
- ввод данных о работниках с клавиатуры;
- хранение информации об объектах класса WORKER с использованием стандартного контейнера `std::vector`;
- вычисление стажа работы сотрудников;
- вывод информации о работниках, стаж которых превышает значение, заданное пользователем;
- вывод информационного сообщения при отсутствии таких работников.

## Структура проекта
- `worker.h` — объявление класса WORKER;
- `worker.cpp` — реализация методов класса WORKER;
- `worker-practice.cpp` — основной файл программы, содержащий функцию `main`.

## Используемые технологии
- язык программирования: C++;
- парадигма программирования: объектно-ориентированное программирование;
- стандартная библиотека C++.

## Результаты
Разработанный программный модуль полностью соответствует требованиям кейс-задачи № 3 и может быть использован в качестве основы для дальнейшего расширения функциональности.
